# Reproduction on uploaded real data (2026-11-01)

Scripts and result files for the datasets uploaded through the data-request tasks (EIA weekly crude stocks, UCI gas turbine, SRMG). Raw data are not stored here (SRMG licence: academic research only; place files under rd/ as in the scripts). Results replace earlier unreproducible figures in the abstracts of s_jpse (EIA) and s_ps (SRMG). Gas-turbine ACI numbers (gt_results.json) are not yet in any abstract.
