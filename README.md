# ایجنت «توسعه بازار برون مرزی هوشمند»
Smart Cross-Border Market Development Agent – Parsa International Group

## چه کاری انجام می‌دهد (هر روز، خودکار)
1. **استخراج RFP و مناقصه‌ها** از TED (اتحادیه اروپا)، بانک جهانی و Find a Tender (بریتانیا)، بر اساس حوزه‌های فعالیت شما در `config.json`.
2. **غربالگری** با کلیدواژه و مهلت، سپس **تحلیل با Claude**: میزان تناسب با محصولات (`products.json`)، الزامات، و تصمیم صادقانه درباره‌ی امکان شرکت:
   - `direct`: امکان شرکت مستقیم ← نامه‌ی ابراز علاقه + چک‌لیست مدارک
   - `partner_required`: نیاز به شریک محلی، چون شرکت سابقه‌ی اجرایی ندارد ← جست‌وجوی شرکای بالقوه در کشور هدف + **پیش‌نویس ایمیل همکاری** + **پیش‌نویس تفاهم‌نامه (MoU)** به‌صورت فایل Word
   - `not_feasible`: کنار گذاشته می‌شود
3. **ذخیره‌ی پیش‌نویس در وب‌میل** (`parsaint.group/webmail` ← پوشه‌ی Drafts) از طریق IMAP. **ایجنت هیچ ایمیلی ارسال نمی‌کند.** خودتان مطالعه، ویرایش و ارسال می‌کنید.
4. **اعلان روزانه** (تلگرام و/یا ایمیل): «اسکن انجام شد – فلان نیاز در فلان کشور در انتظار شماست» + یادآوری مهلت‌ها (۱۴، ۷، ۳ و ۱ روز مانده).
5. **داشبورد** فارسی در `docs/index.html` و **پیگیری هر RFP تا پایان کار** با وضعیت‌ها:
   جدید ← تحلیل‌شده ← در جست‌وجوی شریک / آماده‌سازی پیشنهاد ← مذاکره‌ی تفاهم‌نامه ← نگارش پروپوزال ← ارسال‌شده ← برنده / بازنده

## دستورها
```bash
python -m agent run                 # اجرای کامل روزانه
python -m agent run --no-llm        # فقط استخراج و غربالگری (بدون هزینه‌ی API)
python -m agent list                # فهرست RFPهای فعال
python -m agent status WB-OP00465889 mou_negotiation "شریک X پاسخ داد"
python -m agent redo WB-OP00465889  # تحلیل و پیش‌نویس دوباره برای یک مورد
python -m agent dashboard           # ساخت دوباره‌ی داشبورد
```

## راه‌اندازی آنلاین (پیشنهادی: GitHub Actions، رایگان)
1. یک ریپازیتوری **خصوصی (Private)** در GitHub بسازید و همین پوشه را در آن push کنید.
2. در Settings ← Secrets and variables ← Actions این Secretها را اضافه کنید (توضیح هر کدام در `.env.example`):
   `ANTHROPIC_API_KEY`، `IMAP_HOST`، `IMAP_USER`، `IMAP_PASSWORD`، `TELEGRAM_BOT_TOKEN`، `TELEGRAM_CHAT_ID`
   (و در صورت تمایل `SMTP_*` و `NOTIFY_EMAIL`).
3. فایل `.github/workflows/daily.yml` هر روز ساعت ۷:۳۰ به وقت استانبول اجرا می‌شود. برای اجرای دستی از تب Actions گزینه‌ی **Run workflow** را بزنید.
4. وضعیت RFPها، فایل‌های MoU و داشبورد پس از هر اجرا در همان ریپازیتوری ذخیره می‌شوند.

**ساخت ربات تلگرام:** در تلگرام به `@BotFather` پیام دهید، `/newbot` را بزنید و توکن را بردارید. سپس به ربات خود یک پیام بدهید و `chat_id` را از آدرس `https://api.telegram.org/bot<TOKEN>/getUpdates` بخوانید.

**اجرای محلی به‌جای GitHub:** فایل `.env.example` را به `.env` کپی و پر کنید، سپس `run_daily.ps1` را در Windows Task Scheduler روزانه زمان‌بندی کنید. در این حالت کامپیوتر باید روشن باشد.

## هزینه
فاز استخراج رایگان است. تحلیل با Claude Opus 5.5 حداکثر ۸ تحلیل و ۳ بسته‌ی «شریک + MoU» در روز انجام می‌دهد (قابل تنظیم در `config.json` ← `screening`). هزینه‌ی تقریبی چند دلار در روز است.

## ⚠️ ملاحظات مهم
- **مالکیت فکری:** چند محصول در `products.json` با `ip_check: true` علامت خورده‌اند، چون README آن‌ها می‌گوید برای یک کارفرمای مشخص ساخته شده‌اند. پیش از ارائه‌ی آن‌ها در مناقصه‌ی خارجی، مالکیت حقوقی را روشن کنید. ایجنت نام کارفرمایان را در هیچ مکاتبه‌ای ذکر نمی‌کند.
- **تحریم و انطباق:** ایجنت ریسک‌های انطباق، مثل قواعد واجد شرایط بودن بانک جهانی، تحریم‌ها و کنترل صادرات، را در تحلیل هر مورد علامت می‌زند. تصمیم نهایی با مشاور حقوقی شماست.
- **صداقت:** ایجنت عمداً سابقه، گواهی یا پروژه‌ی جعلی نمی‌سازد و بلوغ محصولات را واقعی بیان می‌کند.
