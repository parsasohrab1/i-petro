# PetroEnergy – کنترل مصرف سوخت و بهینه‌سازی انرژی پتروشیمی‌ها (TRL 4)

محصول هوشمند پترو پالاتوس برای پتروشیمی‌های هلدینگ خلیج فارس: پایش و بهینه‌سازی مصرف سوخت کوره‌ها و دیگ‌های بخار، هوشمندسازی خط تولید و داشبورد مدیریتی.

**سطح بلوغ: TRL 4 (اعتبارسنجی آزمایشگاهی).** همه‌ی خروجی‌ها از شبیه‌سازی ساختگی ۳۰ روزه‌ی هر واحد به‌دست می‌آیند؛ پارامترهای `plants/*.json` نمونه‌اند نه اندازه‌گیری. **TRL 5 فقط** با داده‌ی واقعی همان واحد و اندازه‌گیری در برابر خط مبنا اعلام می‌شود.

## چه می‌کند
| ماژول | کار |
|---|---|
| `physics.py` | راندمان کوره با افت دودکش (Siegert، گاز طبیعی)، هوای اضافی، جریمه‌ی احتراق ناقص (CO)، منحنی راندمان دیگ |
| `optimize.py` | O₂ بهینه‌ی هر کوره (هرگز زیر حد ایمن CO) و تقسیم بار دیگ‌های بخار با کمترین سوخت |
| `analyze.py` | مصرف ویژه‌ی انرژی (MWh/t)، صرفه‌جویی مدل، آشکارساز نشت هوا (انحراف مقاوم O₂)، روند رسوب‌گیری (°C/روز) |
| `dashboard.py` | داشبورد مدیریتی HTML تک‌فایلی (بدون درخواست بیرونی) |
| `simulate.py` | تاریخچه‌ی ساختگی تعیین‌پذیر با یک عیب تزریق‌شده (نشت هوا در کوره‌ی اول) |

## اجرا
```bash
cd products/petro_energy
python -m petro_energy list
python -m petro_energy build --all --out reports     # ۱۶ داشبورد در reports/
python -m petro_energy build --plant arvand --out reports
```
فقط کتابخانه‌ی استاندارد پایتون لازم است. آزمون‌ها: `python -m pytest tests/test_petro_energy.py`.

## واحدها
۱۶ شرکت زیرمجموعه‌ی هلدینگ خلیج فارس (بر پایه‌ی منابع عمومی؛ فهرست و سهام را با هلدینگ تأیید کنید): `plants/<slug>.json`. اروند و خلیج فارس آپادانا از قبل محصول «دوقلوی دیجیتال و بهینه‌سازی فرایند» (TRL 4) دارند و این محصول مکمل آن (انرژی و سوخت) است.

## ارتقا به TRL 5 برای یک واحد
1. فایل `plants/<slug>.json` را با داده‌ی طراحی و تاریخچه‌ی ۶ تا ۱۲ ماه واحد (Historian) جایگزین کنید.
2. به‌جای `simulate.py` داده‌ی واقعی را بخوانید (همان ساختار سطرهای ساعتی).
3. خط مبنای مصرف ویژه را ثبت و پس از اجرای توصیه‌ها اندازه بگیرید.

## جدا کردن مخزن هر پتروشیمی
```bash
tools/split_repos.sh <owner>      # نیاز به gh و دسترسی ساخت مخزن؛ هر واحد یک مخزن خصوصی می‌سازد
```
مخزن‌ها از داخل این جلسه ساخته نشدند، چون دسترسی گیت‌هاب جلسه فقط به همین مخزن است.

## ملاحظه‌ی تحریم
هلدینگ خلیج فارس و چند زیرمجموعه‌اش در فهرست تحریم‌های OFAC (۲۰۱۹) هستند. کار با آن‌ها فقط توسط شرکت ایرانی پترو پالاتوس انجام شود و شرکت بین‌المللی (پارسا اینت) در آن نقشی نداشته باشد؛ پیش از هر همکاری مشورت حقوقی بگیرید.
